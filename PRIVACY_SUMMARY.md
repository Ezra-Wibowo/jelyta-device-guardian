# Privacy & Data Handling Summary

**App Name:** Jelyta Sister's AI Device Guardian  
**Package:** `com.jelyta.deviceguardian`

---

## 🔒 100% Privacy Guarantee
- **Zero Access to Private Data**: The application **does not** read, process, or store SMS, WhatsApp chats, personal communications, contacts list, call logs, or photos/videos.
- **Local-First Processing**: System metrics (RAM, CPU, Storage, Battery) and permission audits are evaluated entirely on-device using official Android system framework services (`ActivityManager`, `PackageManager`, `BatteryManager`).
- **Encrypted Transmission**: Any communication with the Gemini AI Core Engine or FastAPI Cloud Sync Backend uses secure HTTPS/TLS 1.3 protocol. No personal identifiers or sensitive files are ever attached to queries.
