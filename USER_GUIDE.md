# User Guide - Jelyta Sister's AI Device Guardian

Welcome to **Jelyta Sister's AI Device Guardian**!

---

## 📱 Navigation Overview

### 1. Guardian Dashboard Screen
- **Device Health Gauge**: Displays your current device health score (0–100).
- **One-Tap Boost**: Instantly frees unused background memory.
- **Self-Heal**: Runs an automatic system diagnostic.
- **Performance Mode**: Switch between *Normal*, *Battery Saver*, and *Turbo*.

### 2. Optimizer & Healing Screen
- **Lag Cause Analysis**: Shows exact hardware indicators causing performance bottlenecks.
- **Turbo Boost & Cache Clean**: One-click actions to clear cached temporary data and boost RAM.
- **Optimization Log**: Complete history of memory reclaimed and health score impact.

### 3. Security & Privacy Audit Screen
- **Privacy Protection Index**: Overall score evaluating system permission safety.
- **Sensitive Access Counters**: Track how many apps request Camera, Microphone, Location, or Contacts.
- **Risk Level Filter**: Filter installed applications by High Risk, Medium Risk, or Safe.

### 4. AI Assistant & Translator Screen
- **AI Assistant**: Chat with the Gemini AI Core Engine to diagnose battery drain or performance issues.
- **AI Translator**: Translate text across 8+ languages with subtitle generation support.

### 5. Cloud Sync Screen
- Backup configuration profiles and verify connectivity with the FastAPI REST Cloud Backend.
